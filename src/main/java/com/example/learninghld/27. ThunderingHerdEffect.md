When a sudden spike in traffic comes, we should handle it in below ways

- Proper retry
  - Use exponential backoff in retry (Base * 2^n)
  - Use Jitter in exponential backoff to bring randomness (Min(Max wait time, rand(0, base*2^n)))
- Use rate limiter at api gateway itself, before reaching traffic at LB
  - Can use token bucket to smoothen the sudden spike
- Auto scale the system
