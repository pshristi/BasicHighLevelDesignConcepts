# Observability in Distributed Systems

## Logging

**What it is:** Captures detailed events that happen in your system (errors, warnings, debug info, user actions).

**Example Tools:**
- ELK Stack (Elasticsearch, Logstash, Kibana : whole Elastic Stack UI (logs, metrics, security, ML, etc.)) – search & visualize logs.
- Graylog – centralized log management.
- Splunk – enterprise log search and analysis.

## Metrics

**What it is:** Numeric measurements of your system over time (CPU %, memory, request rate, error rate).

**Example Tools:**
- Prometheus – collects and stores metrics.
- Grafana – dashboards to visualize metrics.
- Datadog – hosted solution for metrics + monitoring.

## Tracing

**What it is:** Tracks the path of a request as it flows through multiple services (in microservices architecture).

**Example Tools:**
- Jaeger – distributed tracing system.
- Zipkin – early popular tracing tool.
- New Relic – commercial tracing + APM.

## APM (Application Performance Monitoring)

**What it is:** A broad category that combines logs + metrics + traces + user experience monitoring into one platform.

**Example Tools:**
- AppDynamics
- Dynatrace
- New Relic
